# Frontend Mentor Practice

HTML/CSS front-end layout exercises, practicing component styling and page structure without a framework.

## About
A collection of small front-end practice pages built while learning HTML and CSS. Built January 2023.

## Features
- `project1`: a page with a header banner and a navigation bar
- `project2`: a landing page layout with a hero section and call-to-action

## Tech stack
- HTML5
- CSS3

## Project structure
```
project1/  index.html  style.css
project2/  index.html  style.css
```

## Getting started
Open `project1/index.html` or `project2/index.html` directly in a browser, no build step required.

## Status
Learning project, not maintained.
